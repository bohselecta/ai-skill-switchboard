# Artwork and visual evidence

The three `assets/hero.webp` files are generated editorial illustrations, not screen
captures. They were commissioned for this project on September 30, 2026 using
`fal-ai/nano-banana-pro`. Exact output URLs, request IDs, byte counts, and SHA-256
hashes are in `artwork-provenance.json`. Runtime loads the checked-in files, not an
external image service. The artwork is embedded in standalone builds.

ChatGPT edition: pearl ceramic, graphite tray, mint-lit selected tile. Claude:
ivory/terracotta tiles and paper routing ribbons. Gemini: frosted glass with blue,
lavender, and rose conduits. These evoke distinct visual environments without
copying provider logos or claiming official product authorship.

All requests specified original abstract geometric still life, no words, marks,
people, or screenshots. Human decisions included composition, materials, routing
metaphor, palette, integration, typography, and layout. No claim of exclusive
copyright in raw generated output or third-party trademark clearance is made.
Contributor rights are offered under the accompanying project license to the extent
held. System fonts are used; no third-party font files are distributed. Interface
icons and the grid mark are original inline SVG paths.

`assets/board.png`, when present, is an actual browser capture of the corresponding
running edition using labeled fictional fixtures. It is not an AI-generated mockup.
The full screenshots and browser evidence report are also included in CI artifacts.
